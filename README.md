# NTE AutoFish

基于 OpenCV 图像识别的异环自动钓鱼工具。项目当前提供可视化控制台，支持管理员权限启动、开始/结束运行、实时日志显示和基础统计记录。

## 功能

- 可视化窗口控制自动钓鱼流程
- 窗口内实时显示本次打开后的运行日志，并支持上下滚动
- 窗口内显示本次打开期间和程序总计的钓鱼统计
- ` / ·` 一键开始或结束运行
- `F12` 退出程序
- 自动记录成功钓鱼次数、金色鱼次数、CLICK_BLANK 超时错误到本地 `logs/stats.json`
- 启动时自动请求管理员权限

## 当前钓鱼流程

1. 持续识别 `HOOK` 图标。
2. 识别到 `HOOK` 后，每 0.6 秒按一次 `F`，直到钓鱼条出现。
3. 钓鱼条出现后，识别绿色条和黄色游标，并控制 `A` / `D`。
4. 绿色钓鱼条连续消失后，判断钓鱼小游戏结束。
5. 持续识别 `CLICK_BLANK`，最多等待 20 秒。
6. 识别到 `CLICK_BLANK` 时，点击游戏窗口内空白位置。
7. 20 秒内没有识别到 `CLICK_BLANK` 时，也点击游戏窗口内空白位置，并记录一次 error。
8. 只有确认 `CLICK_BLANK` 后，才记录一次成功钓鱼。
9. 如果绿条消失后等待 `CLICK_BLANK` 的时间大于等于 4.5 秒，则额外记录为金色鱼。
10. 回到第 1 步循环。

钓鱼条不是通过 `assets` 里的 png 模板识别的，而是在固定屏幕区域内做颜色识别：

- 绿色条目标 BGR：`(173, 202, 42)`
- 黄色游标目标 BGR：`(157, 246, 254)`
- 检测区域：`(403, 60, 495, 40)`

## 运行环境

- Windows
- Python 3.14
- 游戏分辨率建议设置为 `1280x720`

## 安装

```powershell
cd NTE_AutoFish
python -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
```

## 使用

推荐双击 `run_gui.vbs` 启动，通常不会显示额外的 cmd 窗口。也可以使用 `run.bat` 作为兼容启动方式。

启动后：

- 按 ` / ·` 或点击界面按钮：开始/结束运行
- 按 `F12` 或点击退出按钮：退出程序

## 项目结构

```text
NTE_AutoFish/
  main.py                # 轻量启动入口和管理员权限处理
  modules/
    gui.py               # Tkinter 可视化控制台
    autofish.py          # 自动钓鱼主流程
    settings.py          # 自动化参数默认值
    controller.py        # 截图、窗口聚焦、鼠标控制
    fish_bar.py          # 钓鱼条颜色识别和 A/D 控制
    keyboard.py          # 键盘输入封装
    logger.py            # 日志配置
    template.py          # 模板识别
  assets/templates/      # HOOK / CLICK_BLANK 等模板
  logs/                  # 本地日志和统计文件，默认不提交
```
