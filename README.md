# NTE AutoFish

基于 OpenCV 图像识别的异环自动钓鱼工具。项目提供 Tkinter 图形界面，支持自动钓鱼、手动卖鱼、按鱼饵消耗次数自动卖鱼、调试截图、运行日志和本地统计。

## 功能

- 自动识别 `HOOK` 提示并按 `F` 开始钓鱼。
- 通过固定区域颜色识别钓鱼绿条和黄色游标，自动按 `A` / `D` 控制。
- 钓鱼结束后识别 `CLICK_BLANK`，点击空白区域返回初始界面。
- 记录本次打开期间的钓鱼数、金色鱼数，以及程序累计统计。
- 可输入当前鱼饵数量，按鱼饵消耗次数递减显示。
- 可输入“钓鱼 N 次后卖鱼”，按鱼饵消耗次数倒计时，归零后在本轮钓鱼结束并回到 `HOOK` 界面时自动卖鱼。
- 调试窗口支持截图、手动卖鱼、调整 `F` 点击频率。
- 启动时自动请求管理员权限。

## 快捷键和退出

- `` ` / 路 ``：开始运行。
- 运行中第一次按 `` ` / 路 ``：请求本轮钓鱼结束后停止。
- 已请求本轮结束后停止时，再按一次 `` ` / 路 ``：立即停止，使用原来的硬停止逻辑。
- `F12`：退出程序。若自动钓鱼正在运行，会先发出立即停止信号，等待工作线程退出后关闭 GUI。
- GUI 右上角关闭按钮和“退出 F12”按钮使用同一套退出逻辑。

## 当前钓鱼流程

1. 等待识别 `HOOK`。
2. 识别到 `HOOK` 后，按设定频率点击 `F`，直到钓鱼绿条出现。
3. 绿条出现时视为消耗一次鱼饵，并更新鱼饵/自动卖鱼倒计时。
4. 控制钓鱼条，直到绿条消失，本轮钓鱼小游戏结束。
5. 等待 `CLICK_BLANK`，确认后点击空白区域。
6. 如果 `CLICK_BLANK` 超时，也会点击空白区域并记录错误。
7. 只有确认 `CLICK_BLANK` 后，才记录一次成功钓鱼。
8. 如果等待 `CLICK_BLANK` 的时间超过金色鱼阈值，会额外记录为金色鱼。
9. 若自动卖鱼倒计时归零，下一轮先等待 `HOOK`，检测到后执行卖鱼流程，再恢复正常钓鱼循环。

## 卖鱼流程

卖鱼核心流程复用于手动卖鱼和自动卖鱼：

1. 聚焦游戏窗口。
2. 按 `Q` 打开 Fishing Master 菜单。
3. 等待 `MENU_OPEN`。
4. 点击鱼仓库标签页。
5. 等待 `WAREHOUSE_READY`。
6. 点击“一键出售”。
7. 等待 `SELL_CONFIRM`。
8. 点击“确认”。
9. 等待 `SELL_SUCCESS`。
10. 点击空白区域关闭成功提示。
11. 等待回到鱼仓库页面。
12. 点击右上角游戏内关闭按钮。

手动卖鱼按钮只执行一次独立卖鱼流程，不会接入自动钓鱼循环。自动卖鱼复用当前自动钓鱼线程里的窗口控制器，不会新建第二套截图/控制流程。

## 图像识别

模板文件位于：

```text
assets/templates/
assets/templates/sell/
```

钓鱼条不是通过 PNG 模板识别，而是在固定区域内做颜色识别：

- 检测区域：`(403, 60, 495, 40)`
- 绿色条目标 BGR：`(173, 202, 42)`
- 黄色游标目标 BGR：`(157, 246, 254)`

卖鱼模板是全窗口透明 PNG，只有目标 UI 区域不透明。

## 运行环境

- Windows
- Python 3.14
- 推荐游戏分辨率：`1280x720`
- 需要管理员权限运行，以便发送键盘和鼠标输入

## 安装

```powershell
cd NTE_AutoFish
python -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
```

## 使用

推荐双击 `run_gui.vbs` 启动，通常不会显示额外的 cmd 窗口。也可以使用 `run.bat` 作为兼容启动方式。

启动后：

- 输入当前鱼饵数量并点击“确认”，可启用鱼饵剩余显示。
- 输入“钓鱼 N 次后卖鱼”并点击“确认”，可启用自动卖鱼倒计时。
- 打开“调试”窗口，可截图、手动卖鱼、调整 `F` 点击频率。
